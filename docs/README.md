# LihaPlayer 文档目录

本文档目录 organized 所有 LihaPlayer 项目的技术文档和用户文档。

---

## 📚 文档组织结构

```
docs/
├── README.md              # 本文件 - 文档导航
├── architecture.md        # 架构决策记录 (ADRs)
├── api/                   # API 设计文档 (如需要)
├── design/               # UI/UX 设计规范
├── testing/              # 测试策略和测试用例
└── user_manual.md        # 用户手册 (Phase 7 生成)
```

---

## 🗂️ 文档说明

### 1. architecture.md
**架构决策记录 (Architecture Decision Records)**

记录所有重要的架构决策，包括：
- 技术选型理由
- 架构模式选择
- 关键依赖的决策过程
- 已知限制和替代方案

**适用读者**: 开发团队、技术负责人  
**更新时机**: 做出重大架构决策时

---

**适用读者**: 最终用户

## 📖 文档编写规范

### 格式要求
- 使用 Markdown (`.md`)
- 文件命名使用 **kebab-case** (如 `user-manual.md`)
- 代码块使用语法高亮标识语言
- 表格对齐，层次清晰

### 内容原则
- **明确受众**: 每篇文档开头标明目标读者
- **先讲为什么**: 技术文档需说明决策理由
- **可操作**: 提供具体步骤、命令、示例
- **保持更新**: 代码变更同步更新文档

---

## 🔄 文档维护流程

1. **新建文档**: 决策/功能完成后 2 天内创建或更新
2. **代码审查**: PR 中需包含相关文档更新
3. **过时标记**: 文档第一行添加 `⚠️ 可能过时` 警告，如果 30 天未验证
4. **版本管理**: 重大文档变更记录在 CHANGELOG.md
