## 一、需求确认汇总

| 决策点 | 选择 | 说明 |
|--------|------|------|
| 库扫描策略 | **混合模式** | 多目录+文件过滤器+手动刷新 |
| 元数据存储 | **本地数据库** | Hive缓存完整元数据 |
| 增量扫描 | **文件监视器** | 实时同步目录变化 |
| 视图展示 | **顶部Tab切换** | 歌曲/艺术家/专辑 |
| 搜索功能 | **综合搜索** | 搜索栏+实时过滤+分类结果 |
| 空库引导 | **内嵌引导** | 库页面内嵌添加按钮 |
| 封面获取 | **懒加载混合** | 列表占位图+详情页异步加载 |

## 三、数据模型

### Song（歌曲）模型

```dart
@HiveType(typeId: 0)
class SongModel extends HiveObject {
  @HiveField(0)
  late String id;              // 唯一标识（文件路径hash）
  
  @HiveField(1)
  late String filePath;       // 文件绝对路径
  
  @HiveField(2)
  String? title;              // 标题（从ID3读取）
  
  @HiveField(3)
  String? artist;              // 艺术家
  
  @HiveField(4)
  String? album;              // 专辑
  
  @HiveField(5)
  String? genre;              // 流派
  
  @HiveField(6)
  late int durationMs;        // 时长（毫秒）
  
  @HiveField(7)
  int? trackNumber;           // 音轨号
  
  @HiveField(8)
  int? year;                  // 年份
  
  @HiveField(9)
  late DateTime addedAt;      // 加入库时间
  
  @HiveField(10)
  late DateTime modifiedAt;   // 文件修改时间
  
  @HiveField(11)
  List<int>? artwork;         // 封面二进制（可选缓存）
  
  @HiveField(12)
  late String artistId;       // 关联艺术家ID
  
  @HiveField(13)
  late String albumId;        // 关联专辑ID
}
```

### Album（专辑）模型

```dart
@HiveType(typeId: 1)
class AlbumModel extends HiveObject {
  @HiveField(0)
  late String id;             // 唯一标识
  
  @HiveField(1)
  String? name;               // 专辑名
  
  @HiveField(2)
  String? artist;             // 专辑艺术家
  
  @HiveField(3)
  int? year;                  // 发行年份
  
  @HiveField(4)
  List<int>? artwork;         // 封面二进制
  
  @HiveField(5)
  late int songCount;         // 歌曲数量
  
  @HiveField(6)
  late String firstSongPath;   // 第一首歌路径（用于封面查找）
}
```

### Artist（艺术家）模型

```dart
@HiveType(typeId: 2)
class ArtistModel extends HiveObject {
  @HiveField(0)
  late String id;             // 唯一标识
  
  @HiveField(1)
  late String name;            // 艺术家名
  
  @HiveField(2)
  late int songCount;          // 歌曲数量
  
  @HiveField(3)
  late int albumCount;         // 专辑数量
}
```

### ScanDirectory（扫描目录）模型

```dart
@HiveType(typeId: 3)
class ScanDirectoryModel extends HiveObject {
  @HiveField(0)
  late String path;            // 目录路径
  
  @HiveField(1)
  late List<String> extensions; // 文件扩展名过滤
  
  @HiveField(2)
  late DateTime addedAt;       // 添加时间
  
  @HiveField(3)
  late DateTime lastScanAt;    // 上次扫描时间
}
```

## 五、核心流程

### 1. 添加目录流程

```
用户点击"添加目录"
       ↓
系统打开目录选择器
       ↓
用户选择目录 → 确认
       ↓
系统显示扫描进度
┌─────────────────────────────────────┐
│  正在扫描...                        │
│  已找到 156 首歌曲                   │
│  ████████████░░░░░░  60%           │
│                                      │
│  正在处理: 七里香.mp3                │
└─────────────────────────────────────┘
       ↓
扫描完成 → 保存到数据库 → 更新UI
```

### 2. 文件监视器流程

```
启动应用
    ↓
加载数据库中的目录列表
    ↓
对每个目录启动watcher
    ↓
监听文件系统事件
    ├── 文件新增 → 提取元数据 → 入库
    ├── 文件删除 → 从数据库移除
    └── 文件修改 → 更新元数据
    ↓
事件处理完毕 → 更新UI通知
```

### 3. 播放歌曲流程

```
用户点击歌曲
    ↓
PlayerProvider.loadAndPlay(filePath)
    ↓
从数据库获取歌曲信息
    ↓
调用AudioDataSource.play()
    ↓
更新PlayerState → UI刷新
```

## 七、设计要点总结

| 决策 | 选择 | 理由 |
|------|------|------|
| 存储 | Hive | 快速、Flutter原生支持 |
| 元数据 | taglib_ffi | 原生性能，支持所有格式 |
| 文件监视 | watcher | 轻量级、事件驱动 |
| 歌曲分组 | 按标题首字母 | 用户查找方便 |
| 详情页 | 下钻页面 | 保持导航上下文 |
| 搜索 | 按Tab筛选 | 符合用户习惯 |
